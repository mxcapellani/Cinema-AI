# Instalação e atualização
```bash
git clone https://github.com/mxcapellani/Cinema-AI.git
cd Cinema-AI
```
Copiar a pasta `.agents/skills/cinema-ai` completa. Reconhecimento automático depende da plataforma; carregar SKILL.md explicitamente quando necessário. Visão depende do host, vídeo depende de ferramenta externa; nenhum plugin é instalado por este pacote.
Atualizar preservando alterações locais, consultar CHANGELOG e repetir os testes. Python/PyYAML são dependências de manutenção. Não solicitar ou armazenar credenciais.
